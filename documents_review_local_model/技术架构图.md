## 2. 单 Agent 审核图（并行模式）

```mermaid
stateDiagram-v2
    [*] --> analyze_outline: START

    state analyze_outline: 结构分析节点
    note right of analyze_outline
        - 解析文档 outline + sections
        - 识别章节/小节层级
        - 生成 outline_summary
        (章节数, 小节数, 章节树)
    end note

    analyze_outline --> plan_strategy

    state plan_strategy: 策略规划节点
    note right of plan_strategy
        - 为每小节分配审核深度
          quick / standard / deep
        - 预检索知识库上下文
          knowledge_context
        - 确定关注标准
    end note

    plan_strategy --> batch_audit: PARALLEL_AUDIT_ENABLED=true

    state batch_audit: 并行审核节点
    note right of batch_audit
        batch_audit_all_sections:
        - asyncio.gather 并发
        - Semaphore 限流
        - 所有小节同时审核
        - 每小节注入 RAG 上下文
        - 条款引用校验
    end note

    batch_audit --> cross_validate

    plan_strategy --> audit_section: 顺序模式

    state audit_section: 顺序审核节点
    note right of audit_section
        - 逐小节审核
        - 注入 RAG + global_context
    end note

    audit_section --> evaluate_result

    state evaluate_result: 结果解析节点
    note right of evaluate_result
        - 解析 JSON metadata
        - 提取 findings / score
        - 条款引用校验结果
    end note

    evaluate_result --> route_eval: 路由判断

    state route_eval <<choice>>
    route_eval --> update_context: 继续
    route_eval --> cross_validate: 全部完成

    state update_context: 上下文更新
    note right of update_context
        - 更新 global_context
        - 追加跨章节上下文
    end note

    update_context --> route_next: 路由判断

    state route_next <<choice>>
    route_next --> audit_section: 下一小节
    route_next --> cross_validate: 全部完成

    state cross_validate: 交叉验证节点
    note right of cross_validate
        - 跨章节矛盾检测
        - 一致性检查
    end note

    cross_validate --> generate_report

    state generate_report: 报告生成节点
    note right of generate_report
        - 汇总所有审核结果
        - 生成最终审核报告
        - contradictions 矛盾清单
    end note

    generate_report --> [*]: END
```

## 5. HITL 检查点交互时序图

```mermaid
sequenceDiagram
    actor U as 用户
    participant F as 前端 agent.html
    participant API as FastAPI 后端
    participant G as Supervisor Graph
    participant S as SQLite Checkpointer

    U->>F: 上传文档 + 开始审核
    F->>API: POST /api/multi-agent/conversation/start

    Note over G: 阶段1: 结构分析
    G->>G: analyze_structure (结构分析)
    G->>S: 保存检查点
    G->>G: checkpoint_structure interrupt()

    API-->>F: SSE: waiting_approval
    F-->>U: 展示章节划分 + [确认] [修改] [重审]

    alt 用户确认
        U->>F: 确认章节划分
        F->>API: POST /conversation/message {approve}
        API->>G: Command(resume=approve)
        G->>S: 加载检查点恢复
    end

    Note over G: 阶段2: 章节审核 (Send API 并行)
    G->>G: dispatch (fan-out N 个 Send)
    par 并行审核
        G->>G: audit_chapter #1
    and
        G->>G: audit_chapter #2
    and
        G->>G: audit_chapter #N
    end
    G->>G: reducer 汇集 chapter_results
    G->>G: dedupe_chapters (去重)
    G->>S: 保存检查点
    G->>G: checkpoint_post_audit interrupt()

    API-->>F: SSE: 审核结果 + waiting_approval
    F-->>U: 展示审核结果 + [确认] [重审] [跳过] [对话]

    alt 用户要求重审
        U->>F: 指定重审章节
        F->>API: POST /conversation/reaudit
        API->>G: re_audit_clear -> dispatch (重审)
        Note over G: re_audit_cycle_count++<br/>上限 MAX_RE_AUDIT_CYCLES=3
    end

    alt 用户确认
        U->>F: 确认审核结果
        F->>API: POST /conversation/message {approve}
        G->>G: synthesize_report (综合报告)
        G->>S: 保存检查点
        G->>G: checkpoint_post_completion interrupt()
    end

    API-->>F: SSE: 审核报告 + waiting_approval
    F-->>U: 展示报告 + [确认] [对话] [导出]

    alt 用户对话
        U->>F: 输入问题
        F->>API: POST /conversation/message
        G->>G: summarize_conversation (如超16条)
        G->>G: chat_response
        API-->>F: SSE: 对话回复
    end

    alt 用户确认完成
        U->>F: 确认完成
        G->>G: finished=true
        API-->>F: SSE: done
    end

    alt 用户导出报告
        U->>F: 点击导出
        F->>API: POST /api/export-review
        API-->>F: Word 文档下载
    end

    Note over G,S: 全程状态自动持久化<br/>支持中断恢复
```
